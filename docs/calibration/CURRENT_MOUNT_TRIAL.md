# 当前试装：D435i 底面贴舌规转接圆盘端面

2026-10-12。用户根据实物照片选定“先试此摆法”；尚未提供最终固定、测量或图像验证结果。适用 AUBO S3、D435i 和蓝色 V1 舌规。

## 1. 本次选定的安装关系

- 接触面：相机带 1/4-20 螺孔和散热槽的窄底面。
- 被接触面：蓝色圆形转接板有四颗螺钉的平整正面，即工具安装端面。它不直接等同于机器人金属法兰安装面，二者之间的距离待测。
- 若底面完整贴平端面，镜头光轴大致平行该端面，与法兰轴线、沿法兰轴线伸出的舌规长杆大致垂直。
- 镜头具体朝端面内哪个方向、相机长边与机器人坐标轴的对应、接触面倾斜和完整平移尚未测定。不能仅凭“底面贴合”确定完整四元数，也不能将贴合解释为光学原点平移为零或误差为零。
- 用户照片中的机身标签可辨认为 D435I；这是照片核验，尚不是 SDK/驱动读取的设备型号或序列号证明。

这里的“朝要抓取物体看”是试装后的观察目标，是否实现须用实际彩色/深度图确认。镜头侧向观察时，需要相应的机械臂观测姿态；不能同时默认镜头沿舌规长杆看，也不能通过修改 TF 把物理侧视变成前视。

## 2. 旧外参示例的适用范围

[旧候选设计](S3_D435I_MOUNT_DESIGN.md) 的玻璃中心 `[100,0,40]` mm、深度原点 `[82.5,0,35.8]` mm，以及光学单位四元数，均属于**镜头沿法兰轴线**的另一种布局。它们不适用于这次端面贴底面的侧视试装。

`examples/calibration/nominal_mount_design.json` 和 `validation/nominal_mount.json` 保留为历史布局的数学回归示例，不能作为当前试装外参。通用 SE(3) 变换、完整姿态处理、TCP 逆补偿和拒绝规则仍有效，无需因安装方式变化而重写。

当前真实站点清单 [site_inventory.json](../../config/calibration/site_inventory.json) 的相机安装边仍为 `UNKNOWN`，translation / rotation 为 null；没有新增猜测数值，也没有发布 TF 或发送运动目标。

## 3. 先试装，再测量

1. 避开螺钉凸起和舌规根部，确保接触定位稳定；需要时用硬质托座/挡块定位，胶带用于压紧。胶带避免遮住镜头、红外窗口和散热槽。记录垫片和接触层，USB 线另行固定在随法兰运动的组件上，避免拉偏相机。
2. 机械臂保持静止，打开彩色图和深度图，检查侧向视野能否完整看到提环、是否被舌规遮挡、提环区域有没有有效深度。若看不到，先调整物理朝向或观测姿态，再冻结装配。
3. 记录机器人金属法兰中心 / 安装面、蓝色圆盘正面、相机底部螺孔轴线和前玻璃的实际关系。至少测平面内两个方向的定位距离、蓝色圆盘到金属法兰面的轴向距离、相机接触层厚度，并相对法兰物理标记记录镜头与长边方向。
4. 绑定实际 `wrist3_Link` / `ee_link` 参考系，按测量或 CAD 得到完整变换初值；尺量/CAD 结果仍标 ESTIMATED。17.5 mm 螺孔中心线参考尺寸必须沿实际相机轴旋转后合成，不能直接沿法兰固定 X 轴减去。
5. 按 [现场 SOP](FIELD_SOP.md) 采集手眼与独立验证数据，确认误差后交接。拆装、滑移或改变垫片后重新复核。
